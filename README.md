# Sahinul Islam Laskar

I build and run automation systems for content websites — SEO measurement, price tracking, and deal monitoring — and I write about what actually works.

## What I work on

- **SEO systems** — Google Search Console tooling for small site owners: prompt-query (AEO) scanning, quick-answer tracking, cannibalisation checks and Core Web Vitals monitoring, all at zero tool cost.
- **Price tracking** — lightweight trackers for Indian marketplaces and brand stores, built on a single SQLite file.
- **Telegram automation** — resilient channel monitoring with watchdogs and backoff, learned the hard way in production.
- **WordPress tooling** — must-use plugins that render prices and derived figures from a live price store, so published numbers never go stale.

## Open source — in progress

I am open-sourcing the systems above, one at a time, each after a research and sanitisation pass:

1. [PriceOnce — Live Price Shortcodes for WordPress](https://github.com/iSahinul/PriceOnce) — published, v0.1.0
2. [SERPLens — SEO toolkit for Search Console (AEO prompt-scan)](https://github.com/iSahinul/SERPLens) — published, v0.1.0
3. [PriceSpyglass — store-agnostic price tracker with deal scores](https://github.com/iSahinul/PriceSpyglass) — published, v0.1.0
4. Telegram Deal Poller — in the queue
